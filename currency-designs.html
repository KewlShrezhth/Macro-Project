Macro Project · Part 2 · Currency Design Creation

American Note Series 2026

A redesign of all six U.S. notes, front and back. Each note has one theme drawn from the American story and its own color. Every note uses the same layout, so the security and accessibility features sit in the same place on every value.

Inspect

Security features

  1. S1
    Color-shifting numeralThe large numeral at the lower right of the front is printed in color-shifting ink. It looks copper when the note lies flat and turns green when tilted. Copiers and printers can't reproduce the shift.
  2. S2
    Denomination security threadA plastic strip embedded in the paper reads "USA" and the value. Its position is different on every note, and it glows its own color under UV light.
  3. S3
    Watermark windowAn unprinted oval holds a faint copy of the note's main image. You can see it from both sides when you hold the note up to light.
  4. S4
    Microprinting (extra)The border repeats "The United States of America" and the value in text too small to copy cleanly.

Accessibility features

  1. A1
    Extra-large, high-contrast numeralA plain panel on the back holds a numeral more than half the note's height, printed in the darkest ink on an unprinted field, for people with low vision. The front repeats a large numeral at the top left.
  2. A2
    Tactile dot codeRaised dots on the short edge let blind users tell notes apart by touch: $1 has 1 dot, $5 has 2, $10 has 3, $20 has 4, $50 has 5 and $100 has 6.

The color system

Every note uses three strengths of one hue: a dark ink for type and line work, a middle tone for the imagery, and a pale tint for the paper.

Design consistency check

1. How does your color scheme create a consistent system across all denominations while remaining distinct for each value?

Every note follows the same color formula: one hue in three strengths. A dark ink is used for text and line work, a middle tone for the main image, and a pale tint for the paper. Because every note is built the same way, the six read as one family. Only the hue changes: sage green for $1, violet for $5, amber for $10, teal for $20, crimson for $50 and navy for $100. I put values that are next to each other far apart on the color wheel, so notes that are easy to mix up, like the $5 and $10 or the $20 and $50, never look alike. Color is never the only cue. The large numerals, the tactile dots and the UV thread color back it up, so people who are color-blind can still tell the notes apart.

2. How do your front and back designs work together as a cohesive unit?

Each note tells one theme across both sides. The front shows the theme's symbol, like the torch for Liberty, the canyon for The Land and the rocket for Discovery. The back shows the wider scene around it: New York Harbor, the Colorado River, and Earth seen from the Moon. Both sides share the same frame, microprinted border, typefaces and color. The physical features line up through the paper. The watermark window, the security thread and the tactile dots sit in mirrored positions, so each is in the same spot whichever side you look at. The two sides also split the work. The front carries the main image and the color-shifting numeral. The back carries the serial numbers, both seals and the big accessibility numeral.

Production notes

  • Hand-drawn
  • ✓Computer-generated
  • Mixed media

All notes are drawn as vector graphics in the same 2.61 : 1 proportion as today's notes (6.14 × 2.61 in). One shared template is used for every value, so the layout, feature positions and type are identical across the series. Each note is marked SPECIMEN because it's a design study.
